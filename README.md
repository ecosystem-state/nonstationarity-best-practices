# Time-varying relationships in ecological modeling

This repository includes data, code, and model output for: Feddern, M.L., Litzow, M.A., Ward, E.J., Ryznar, E.R., Hunsicker, M.E., Satterthwaite, E.V., Wor, C., Anderson, S.C., Satterthwaite, W.H., Malick, M.A., Greenberg, Jacox, M.G., and Connors, B.M.  Nonstationary relationships in ecological modeling. Ecosphere.

## Additional Information
No primary data was used in this analysis. All data was from previously published sources. For all case studies, the "Appendix_.qmd" files can be considered the final, clean analysis. Additional scripts and quarto documents include supporting exploratory analyses and data processing.
